# auction-renamer

Утилита для переименования лотов и файлов перед загрузкой на аукцион.
Репозиторий-заготовка: здесь появятся правила именования, пакетная обработка
фотографий и проверка дублей.

## Зачем

Аукционные лоты удобнее вести, когда имена файлов и позиций собираются по
одному шаблону: дата, категория, номер лота, короткое название. Руками это
быстро превращается в кашу, поэтому — скрипт.
